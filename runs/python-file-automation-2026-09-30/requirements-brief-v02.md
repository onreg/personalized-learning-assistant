## Learning goal

Learn Python file automation well enough to build a command-line script that sorts copies of files from a sample Downloads folder into subfolders by extension, shows a dry run before moving anything, and has automated tests.

## Current knowledge

Knows Python variables, loops, and functions; has little experience with filesystem APIs.

## Available time

Two hours per week for five weeks (10 hours total).

## Constraints

- Work on Windows.
- Use free English learning resources.
- Practice only on disposable sample files, never personal files.
- The finished project is a command-line script with a dry run and automated tests.

## Intended outcome

A tested command-line script that displays what it would do in a dry run, then sorts copies of files from a disposable sample Downloads folder into extension-based subfolders when run for real.

## Unresolved assumptions

- The learner says both "sorts copies of files" and "before moving anything." Whether execution copies source files or moves already-created copies is a project design detail to settle during planning; the brief does not assume either behavior.
